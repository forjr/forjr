# create-forjr

Makes a new project of [Forjr](https://github.com/forjr/forjr), the full-stack React framework built for AI.

```sh
npm create forjr my-app
cd my-app
npx forjr dev
```

It runs `forjr new my-app` of the newest `forjr`, which writes the project and installs its `forjr`. The docs ship inside it: `npx forjr docs`.
